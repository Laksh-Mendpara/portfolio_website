## ✨ Preview

A cyberpunk-themed "under maintenance" page featuring:

- 🌌 **Animated Particle System** - 50+ floating particles with randomized paths
- 🔢 **Matrix Rain Effect** - Falling Japanese characters like in The Matrix
- ⚡ **Glitch Text Animation** - Eye-catching title with RGB split effect
- 💻 **Terminal Output** - Fake build process with typing animation
- 🔮 **Floating 3D Card** - Profile card with animated gradient border
- 🌈 **Neon Glow Effects** - Cyan, purple, and green accents throughout
- 📊 **Progress Bar** - Animated construction progress indicator

## 🛠️ Tech Stack

- **Framework:** React 18.3
- **Build Tool:** Vite 6.0
- **Styling:** Pure CSS (no frameworks - all custom animations)
- **Fonts:** Inter + Fira Code (via Google Fonts)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Laksh-Mendpara/portfolio_website.git
cd portfolio_website

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
